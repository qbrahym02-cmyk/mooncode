# مدونة قواعد السلوك لمجتمع Moon Code

## التزامنا

نلتزم بمجتمع ترحيبي وآجميع لجميع المشاركين — بغض النظر عن العمر، الجنس، الهوية الجنسية، التعبير الجنساني، التوجه الجنسي، الإعاقة، المظهر الجسدي، حجم الجسم، العرق، الإثنية، الدين، الجنسية، أو المستوى التقني.

نهدف لأن يكون مجتمع Moon Code **خاليًا من التحرش** للجميع.

## سلوكنا المتوقع

- **استخدم لغة ترحيبية وشاملة**.
- **احترم وجهات النظر المختلفة**.
- **تقبل النقد البناء**.
- **ركّز على ما هو أفضل للمجتمع**.
- **أظهر تعاطفًا تجاه أعضاء المجتمع الآخرين**.

## سلوكنا غير المقبول

- **استخدام لغة أو صور جنسية**.
- **الترهيب أو الملاحقة**.
- **التشهير أو الإذلال**.
- **نشر معلومات خاصة بدون إذن** (doxxing).
- **سلوك آخر غير مهني** في بيئة مجتمعية.

## سلطات الإشراف

أعضاء المجتمع المسؤولون عن تطبيق هذه المدونة لديهم حق:

- إزالة أو تعديل أو رفض تعليقات/commits/كود/ويكي/قضايا.
- حظر مؤقت أو دائم لأي سلوك يعتبر غير ملائم.

## نطاق التطبيق

تنطبق هذه المدونة على:
- جميع المساحات العامة للمشروع (GitHub Issues، PRs، Discussions).
- أي مساحة يمثل فيها الفرد المشروع أو مجتمعه.

## الإبلاغ

حالات السلوك غير المقبول يمكن الإبلاغ عنها عبر:

- **فتح Issue خاص** على GitHub (للمسائل غير الحساسة).
- **إرسال بريد إلكتروني** للمشرف (سيُضاف قريبًا).

كل البلاغات سيتم مراجعتها والتحقيق فيها بعناية وسرية.
