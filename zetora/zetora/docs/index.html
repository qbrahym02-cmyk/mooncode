أسئلة شائعة

هل Moon Code مجاني؟ +
نعم، Moon Code مجاني تمامًا ومفتوح المصدر تحت رخصة MIT. يمكنك استخدامه وتعديله وتوزيعه بحرية.
هل بياناتي آمنة؟ +
نعم. Moon Code يعمل محليًا (local-first) — بياناتك تبقى على جهازك. لا سحابة، لا تتبع. كل تعديل يطلب موافقتك الصريحة أولًا.
كيف أحدّث Moon Code؟ +
اكتب: mooncode update — وهذا كل شيء. النظام يتحقق من GitHub Releases ويحدّث تلقائيًا من أي مكان في العالم. يمكنك أيضًا استخدام mooncode check-update للتحقق فقط.
ما المزوّدين المدعومين؟ +
OpenAI، Anthropic، Google، OpenRouter، Ollama، وأي مزوّد متوافق مع OpenAI API. يمكنك أيضًا استخدام وضع demo بدون أي مفاتيح.
هل يدعم العربية؟ +
نعم! Moon Code مصنوع للناطقين بالعربية — واجهة عربية كاملة، دعم RTL، ووثائق بالعربية.
ما هي متطلبات التشغيل؟ +
Node.js 20.12 أو أحدث فقط. لا تبعيات تشغيل خارجية. تطبيق سطح المكتب يعمل بدون أي متطلبات إضافية.
