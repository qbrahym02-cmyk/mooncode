FAQ

What is Moon Code?+
Moon Code is an open source AI coding agent that runs in your terminal, desktop, or IDE. It helps you write, edit, and understand code with explicit approval for every action.
How do I use Moon Code?+
Install via npm i -g mooncode or curl -fsSL https://mooncode.dev/install | bash, then run mooncode start.
Do I need extra AI subscriptions?+
No. Moon Code works with a free demo mode. You can also connect your existing OpenAI, Anthropic, Google, or local Ollama models.
Can I only use Moon Code in the terminal?+
No. Moon Code is available as a terminal interface (TUI), a desktop app for macOS/Windows/Linux, and a web interface.
How much does Moon Code cost?+
Moon Code is free and open source under the MIT license. You only pay for any AI API keys you choose to use.
What about data and privacy?+
Moon Code is local-first. Your code and data never leave your machine. The agent only contacts AI providers when you send a message.
Is Moon Code open source?+
Yes! Moon Code is MIT licensed and available on GitHub.
